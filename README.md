🌷 *Pequenos passos, grandes descobertas!*

Olá, visitante! Seja muito bem-vindo(a) ao meu cantinho de estudos. 💗

Este repositório faz parte da minha jornada de aprendizado no curso de **Desenvolvimento Full Stack Python da EBAC**.

Aqui vou explorar ferramentas e conceitos importantes para quem está começando no mundo do desenvolvimento de software. 🧚

## 🌱 O que estou aprendendo?

- 🍃 **Git:** controle de versão e histórico de alterações.
- 💻 **GitHub:** hospedagem de repositórios e colaboração.
- 🌿 **Branches:** desenvolvimento de novas funcionalidades de forma organizada.
- 📨 **Pull Requests:** revisão e integração de alterações.

## 🍓 O objetivo deste projeto

Praticar o fluxo de trabalho com Git e GitHub, desde a criação de um repositório até a integração de alterações por meio de um Pull Request.

## 🌙 Minha filosofia de aprendizado

> Cada linha de código é uma sementinha. Com paciência, curiosidade e prática, ela pode florescer em algo incrível. 🌷
